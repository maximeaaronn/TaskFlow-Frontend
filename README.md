# TaskFlow - Frontend

## Présentation du projet
Application interactive de gestion de tâches développée avec React. Elle permet de structurer et de suivre ses tâches de manière ergonomique.

### Technologies utilisées
- React (Vite)
- React Router DOM
- CSS

#### Fonctionnalités
- Affichage, ajout, modification et suppression de tâches,
- Sécurisation des routes et vérification des accès utilisateurs,
- Communication asynchrone avec l' API REST Laravel,

##### Installation et Lancement
1. Installer les dépendances : `npm install`
2. Lancer le serveur : `npm run dev`
